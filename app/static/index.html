YOLOv8 Detection API

Pretrained YOLOv8n (COCO, 80 classes) exported to ONNX and served by FastAPI on a CPU. Pre- and post-processing (letterbox, decode, NMS) and the IoU tracker are plain NumPy. Endpoints: /docs · /health · /metrics · GitHub

Pick an image, a short clip or your webcam.
Raw JSON response

  
Video mode samples 5 frames/s on the server, runs them in batches through one ONNX session, and links boxes into tracks so each object is counted once. Webcam mode posts a downscaled frame to /detect in a loop. When self-hosted, /ws/detect streams over a WebSocket instead.
